# Gato's Visual Novel

Foundry VTT v13용, 시스템 무관 비주얼 노벨 연출 모듈입니다. **Gato's Chat Tools 0.2.0 이상**과 **gatos-lib**(0.4.0부터; 설치만 되고 비활성이면 ready에서 경고)이 필요합니다. 기능·API·설정 키·lang 키·플래그·아카이브 형식은 0.3.0과 같습니다.
설계 문서는 [PLAN.md](PLAN.md)에 있습니다.

## 기능

### 표정 / 스탠딩
- 액터마다 **표정 항목**(이름 + 얼굴 이미지 + 스탠딩 이미지)을 여러 개 등록합니다. 모든 액터는 지울 수 없는 **기본** 항목을 가집니다.
- 편집기 열기: 액터 시트 머리말의 **표정/스탠딩** 버튼, 액터 목록 우클릭 메뉴, 발화자 바 표정 줄의 톱니, 매크로 `game.modules.get("gatos-visual-novel").api.openExpressionConfig(actor)`.
- 편집기: 왼쪽 목록(끌어서 또는 ▲▼로 순서 변경, 기본은 맨 위 고정), 오른쪽에서 이름·얼굴·스탠딩 지정. 미리보기에 "이 표정으로 말하면 카드엔 이 얼굴, 노벨창엔 이 스탠딩"과 그 이미지의 출처가 나옵니다. 아래에서 액터 전체 스탠딩 크기·세로 위치를 보정합니다.
- 얼굴만 있거나 스탠딩만 있는 항목도 됩니다. 비어 있으면 다음 순서로 대체합니다.
  - 채팅 카드(얼굴): 이 항목 얼굴 → 이 항목 스탠딩 → 기본 얼굴 → 토큰 → 액터 이미지
  - 노벨창(스탠딩): 이 항목 스탠딩 → 이 항목 얼굴 → 기본 스탠딩 → 토큰 → 액터 이미지
- 편집 권한: 액터 소유자 또는 GM.

### 표정 고르기
- 채팅 발화자 바 아래에 **표정 줄**이 생깁니다(현재 화자가 액터일 때). 누르면 그 액터의 현재 표정이 바뀌고 발화자 바 초상화도 바뀝니다. 현재 표정은 사용자별·액터별로 기억합니다.
- **인라인 태그**: 메시지를 `{웃음} 와, 너 진철이랑 해변도 갔었어?` 처럼 중괄호 한 겹의 표정 이름으로 시작하면 그 메시지만 그 표정으로 보냅니다(태그는 지워짐). 없는 이름이면 그대로 둡니다. "인라인 태그로 현재 표정 바꾸기"를 켜면 이후에도 그 표정이 유지됩니다.
- 메시지를 보낼 때 표정·얼굴·스탠딩이 **메시지에 고정**되므로, 나중에 표정 이미지를 바꿔도 이미 올라온 카드와 노벨창 기록은 바뀌지 않습니다. 채팅 도구 수정 창에서 화자를 바꾸면 새 화자의 기본 표정으로 다시 고정됩니다.

### 노벨창
- 사이드바(채팅창)와 핫바를 뺀 캔버스 위 영역에 스탠딩과 대사창을 띄웁니다. 캔버스 조작(토큰 선택·이동)은 그대로 됩니다.
- 말한 캐릭터의 스탠딩이 무대에 서고 대사창에 이름과 대사가 나옵니다. 지금 말하는 캐릭터만 컬러, 나머지는 회색(설정으로 어둡게/그대로).
- 동시에 최대 6명(설정 1~6). 새 화자는 가운데부터 바깥으로 자리를 잡고, 자리가 없으면 가장 오래 말하지 않은 캐릭터가 내려갑니다. 배치는 "고르게"(선 사람 수에 맞춰 벌림) 또는 "고정 칸".
- 같은 액터의 토큰 여러 개는 한 스탠딩입니다. 스탠딩이 없는 화자(액터·토큰 모두 없음)는 대사창만 바뀝니다.
- 귓속말은 받은 사람 화면에만, 잡담은 무대에 반영하지 않습니다. OOC는 기본으로 "GM의 OOC만 서술로"(이름표 없는 대사창), 굴림은 기본 무시(설정으로 플레이버+합계를 서술로).
- 접속하거나 새로고침하면 최근 메시지(기본 40개)로 무대를 복원하므로 늦게 들어온 플레이어도 같은 무대를 봅니다.
- 대사창 오른쪽 위: ▾ 접기, 빗자루(GM: 모두의 무대 비우기), × 노벨창 끄기. 대사창을 누르면 타자 효과가 바로 끝납니다.
- GM은 **Alt를 누른 채 스탠딩을 우클릭**하면 모두의 무대에서 그 스탠딩을 내립니다.
- 전투 중 숨김, 자동 퇴장(분), 타자 효과, 대사창 투명도·글자 크기, 스탠딩 높이는 설정에서 고릅니다.

### 켜기 / 끄기
- 채팅 컨트롤 바(채팅 도구 상자 아이콘 옆)의 **가면 아이콘**으로 자기 노벨창을 켜고 끕니다. 키 설정 "노벨창 켜기/끄기"도 있습니다(기본 미지정).
- 가면 아이콘 **우클릭 메뉴**: (GM) 전원 노벨창 켜기 / 전원 끄기 / 전원 무대 비우기, 무대 다시 구성, 키워드 등록부.
- GM의 전원 켜기/끄기는 각자의 설정을 바꾸는 방식이라 플레이어가 다시 바꿀 수 있습니다. 막으려면 "플레이어가 노벨창을 켜고 끌 수 있음"을 끄세요(플레이어 가면 버튼과 × 버튼이 숨겨짐).
- "전원 무대 비우기"는 시점을 월드에 기록하므로 새로고침해도 그 이전 메시지로는 무대를 복원하지 않습니다.

### 키워드 링크와 참조 이미지
- 채팅에 `{{해변 사진}}` 또는 `{{해변 사진|그 사진}}` 처럼 쓰면 그 문서로 가는 링크가 됩니다. 키워드는 ① 키워드 등록부 ② 액터 → 아이템 → 저널 → 저널 페이지 이름(대소문자 무시, 정확히 일치) ③ `저널명/페이지명` 순으로 찾습니다.
- 링크는 **보낸 사람**이 GM이거나 그 문서에 **관찰자 이상**(설정으로 제한/관찰자/소유자) 권한이 있을 때만 만들어집니다. 안 되면 원문을 남기고 경고를 띄웁니다.
- 링크를 누르면 같은 권한이 있는 사용자에게만 문서 창이 열리고, 없으면 경고가 나옵니다(노벨창 대사창 안의 링크도 같음).
- 링크가 걸린 메시지가 오면 노벨창 가운데에 그 문서의 **참조 이미지**(액터·아이템 이미지, 저널의 첫 이미지 페이지, 이미지가 없으면 텍스트)가 뜹니다. 여러 개면 아래 탭으로 바꾸고, 누르면 문서가 열립니다. 권한이 없는 사용자에게는 이름만 있는 자물쇠 카드가 나옵니다. 다음 대사가 오면 사라집니다.
- 저널·아이템 설명 등 채팅 밖에서도 같은 문법이 링크로 보입니다(보는 사람 권한 기준, 참조 이미지 없음).
- **키워드 등록부**(가면 아이콘 우클릭 → 키워드 등록부, 매크로 `api.openKeywordManager()`): 키워드와 문서를 짝지어 등록합니다. 문서를 창에 끌어다 놓으면 UUID가 채워집니다. 플레이어는 자기가 관찰자 이상인 문서만 등록하고 자기 항목만 지울 수 있으며, 접속한 GM 클라이언트가 대신 저장합니다.

### 아카이브 / 내보내기 (Gato's Chat Tools 연동)
- 카드 포트레잇·아카이브 뷰어·HTML 내보내기에 고른 표정의 얼굴이 쓰이고, 포트레잇에 마우스를 올리면 표정 이름이 나옵니다.
- 아카이브 JSON의 각 메시지에 `vn`(표정 id·이름·얼굴·스탠딩, 참조 문서, 노벨창 분류, 스탠딩 자리 키)이, 머리말에 `vn`(슬롯 수·순서)이 기록됩니다.
- **ZIP / 폴더** 내보내기: 링크된 문서마다 `refs/<종류>-<id>.html` 서브 페이지(이미지·텍스트, 채팅 로그로 돌아가기 링크)와 `refs/images/`가 함께 나가고, 로그의 링크를 누르면 새 창으로 열립니다. 메시지에 쓰인 스탠딩·얼굴 이미지는 `stands/`·`faces/`에 담기고(설정으로 끌 수 있음), 로그 JSON(`<로그 이름>.log.json`)의 경로는 모두 번들 기준 상대 경로입니다.
- 단일 HTML·새 창 모드에는 서브 페이지가 없고 링크는 이름만 남습니다.

### 로그 플레이어
지난 대화를 노벨창으로 다시 봅니다. 월드 안에서 보는 방법과, 내보낸 폴더를 PC에서 바로 여는 방법이 있습니다. 둘 다 같은 재생 코드(`player-core.js`)를 씁니다.

**월드 안에서**
- 가면 아이콘 우클릭 → **로그 재생…** → "현재 채팅 로그" 또는 저장된 아카이브를 고르고 재생. 매크로: `game.modules.get("gatos-visual-novel").api.player.open()`
- 채팅 도구 **아카이브 뷰어**의 **노벨로 재생** 버튼(chat-tools 0.3.1 이상): 지금 목록에 보이는 메시지(검색·화자·날짜·종류 필터 적용 후)를 재생합니다. 선택 모드의 선택 막대에 있는 같은 버튼은 고른 메시지만 재생합니다. 재생을 시작하면 뷰어는 최소화됩니다.
- 노벨창 위쪽에 재생 막대가 생깁니다: 처음 / 이전 / 재생·일시정지 / 다음 / 끝, 탐색 바, 위치(12 / 340)와 시각, 속도(0.5~3배), ☰ 메시지 목록(누르면 그 대사로 이동), ✕ 재생 끝내기.
- 대사창을 누르면 타자 중인 줄은 바로 끝까지, 다 나온 줄이면 다음 대사로 넘어갑니다. 자동 재생은 대사 길이에 맞춰 넘깁니다.
- **나에게만** 보이는 재생입니다. 다른 사용자의 노벨창은 바뀌지 않고, 재생 중에도 실시간 무대는 뒤에서 계속 갱신되어 재생을 끝내면 바로 돌아옵니다. 노벨창을 꺼 둔 상태에서도 재생할 수 있습니다.
- 플레이어에게는 아카이브 뷰어와 같은 규칙으로 남의 귓속말·비공개 굴림이 빠집니다. OOC·굴림 처리는 자기 설정을 따릅니다.
- 이 모듈 설치 전에 저장한 아카이브도 재생됩니다(표정 정보가 없으면 카드 포트레잇을 스탠딩으로 씀).

**PC에서 (내보낸 폴더)**
- 채팅 도구의 ZIP/폴더 내보내기에 `<로그 이름>.player.html`이 함께 들어가고, 로그 HTML 맨 위에 "▶ 노벨 플레이어로 보기" 링크가 생깁니다.
- zip을 풀고 `player.html`을 더블클릭하면 아무 브라우저에서나 재생됩니다. 설치·서버·인터넷이 필요 없고, 폴더째 다른 사람에게 보내도 됩니다. 대사 데이터와 재생 코드가 파일 안에 들어 있어 `file://`에서도 동작합니다.
- 키보드: Space 재생/정지, → 또는 Enter 다음, ← 이전, Home/End 처음/끝. 주소 끝의 `#12`는 지금 위치로, 그 주소를 열면 12번째 대사부터 시작합니다.
- 키워드 링크와 참조 이미지를 누르면 `refs/` 서브 페이지가 새 탭으로 열립니다.
- 무대 규칙(스탠딩 수·배치·회색 처리·대사창 크기·타자 속도·OOC/굴림 처리)은 내보낸 사람의 설정을 따릅니다.

**편집기 (내보낸 플레이어 안, 0.3.0)**
- 재생 막대의 **✎** 를 누르면 오른쪽에 편집기가 열립니다. 잘못 친 대사·표정·화자를 뒤늦게 고치거나, 줄을 지우고 끼워 넣고, 배경을 깔 수 있습니다. 월드 안 재생에는 없습니다(월드에서는 채팅 도구의 편집을 쓰세요).
- 고른 줄(지금 재생 위치, 또는 아래 목록에서 누른 줄)의 **종류**(대사 / 독백·행동 / 서술 / 장면 전환), **화자**(로그에 나온 캐릭터), **표시 이름**, **표정**, **스탠딩·얼굴 그림**, **배경**, **대사**를 바꿉니다. 바꾸는 즉시 무대에 반영됩니다.
- **표정 고르기**는 그 캐릭터가 로그에서 쓴 표정을 먼저 보여 주고, 그 아래에 번들의 모든 스탠딩을 보여 줍니다. "이어지는 같은 표정의 대사도 함께 바꾸기"를 켜 두면(기본) 뒤따르는 같은 캐릭터의 같은 표정 줄까지 한 번에 바뀝니다(발화 때 표정을 안 바꿔서 여러 줄이 잘못된 경우).
- 그림 고르기 창에는 로그에 나온 그림(`stands/`·`faces/`·`portraits/`·`images/`·`refs/images/`)이 뜹니다. **번들 폴더 열기(📁)** 로 내보낸 폴더를 열면 그 폴더 안에 직접 넣어 둔 그림(`backgrounds/` 포함)도 목록에 올라옵니다. **파일에서…** 로 PC의 아무 그림이나 고를 수도 있고, 경로를 직접 적을 수도 있습니다.
- **배경**은 "이 줄부터"의 뜻입니다. 안 바꾼 줄은 앞 줄의 배경을 이어받고, "이 줄부터 배경 없음"으로 지웁니다. 종류를 **장면 전환**으로 두면 대사 없이 배경만 바뀌는 줄이 되고, "스탠딩 모두 내리기"로 장면을 비울 수 있습니다.
- **대사**는 보통 글로 고칩니다(빈 줄 = 문단, 줄바꿈 = `<br>`). 링크·루비 등 서식이 있는 줄은 자동으로 "HTML로 편집"이 켜집니다.
- 줄 조작: 앞에/뒤에 삽입(같은 화자로 새 줄), ↑↓ 이동, 삭제. 되돌리기/다시 실행(Ctrl+Z / Ctrl+Shift+Z, 편집기 안에서). 재생되지 않는 줄(남의 OOC 등)도 목록에 흐리게 보이며 종류를 바꾸면 재생됩니다.
- **저장**(Ctrl+S): 처음엔 내보낸 폴더를 묻고(플레이어 파일이 있는 폴더여야 함), `<이름>.player.html`·`<이름>.log.json`을 그 자리에 덮어씁니다. "파일에서…"로 고른 새 그림은 `stands/`·`faces/`·`backgrounds/`에 복사됩니다. 폴더에 쓸 수 없는 브라우저(Firefox 등)에서는 **⤓ 내려받기**로 두 파일을 받아 바꿔 넣으세요(이때 새 그림은 페이지 안에 포함됩니다).
- 저장하지 않은 편집은 브라우저에 초안으로 남아, 같은 파일을 다시 열면 불러올지 묻습니다. 편집한 줄에는 ✎ 표시가 붙고 로그 JSON 머리말에 `edited`가 기록됩니다.
- 편집기는 0.3.0 이후에 내보낸 `player.html`에만 들어 있습니다. 이전 내보내기는 월드에서 다시 내보내세요.

**화면 설정(스탠딩 배치·높이·회색 처리, 대사창 불투명도·글자 크기, 타자 효과)** 은 GM이 모듈 설정에서 정한 값이 모든 사용자의 기본값입니다. GM이 바꾸면 접속 중인 모두에게 바로 반영됩니다. 각자 화면에서 다르게 보고 싶으면 모듈 설정의 **노벨창 화면 설정 (개인) → 내 화면 설정**에서 원하는 항목만 "내 값 사용"으로 바꿉니다. 체크한 항목만 개인 값으로 남고, 나머지는 계속 GM 기본값을 따릅니다. "모두 GM 기본값으로"를 누르면 개인 값이 모두 지워집니다. 액터별 스탠딩 크기·세로 위치 보정(표정 편집기)은 액터에 저장되므로 원래부터 모두에게 같습니다. 내보낸 `player.html`에는 내보낸 사람 화면 기준 값이 들어갑니다.

## API
`game.modules.get("gatos-visual-novel").api`
- `getExpressions(actor)`, `setExpressions(actor, list, stand?)`, `resolveImages({actor, token, expressionId})`
- `getCurrentExpression(actorId)`, `setCurrentExpression(actorId, id)`
- `openExpressionConfig(actor)`, `openKeywordManager()`
- `stage.enable() / disable() / toggle() / clear() / remove(key) / getState() / rebuild()`, `broadcastStage(enabled)`(GM)
- `player.open()`(기록 고르기 창), `player.playSource(archiveId | "__live__", opts)`, `player.play(messages, opts)`(직렬화 메시지 배열), `player.loadSource(source)`, `player.stop()`, `player.isPlaying()`
- `resolveKeyword(text, user)`, `openRef(ref)`, `toEntry(message)`, `describe(message)`
- `StageState`(무대 리듀서), `StageDOM`(무대 렌더러), `PlayerCore`(재생 엔진) — 세 파일과 `player-editor.js`(편집기)는 Foundry 전역을 쓰지 않아 내보낸 `player.html`에 그대로 들어갑니다. 내보낸 페이지에서는 `window.gvnPlayer`·`window.gvnEditor`로 접근합니다.
- 훅: `gvnStageChanged(state, entry)`, `gvnExpressionsUpdated(actor)`, `gvnRefOpened(ref)`, `gvnPlaybackStarted(player)`, `gvnPlaybackEnded(player)`

## 참고
- 노벨창은 `#interface` 안에서 캔버스 위·UI 아래(z-index 1)에 깔리므로 창·사이드바·핫바·토큰 HUD가 가려지지 않습니다. 비슷한 모듈(theatre, lichsoma-speaker-stage, cinematic-cut-ins)과 함께 켜면 겹칠 수 있습니다.
- v14는 아직 실측하지 않았습니다(`compatibility.verified: 13`). 버전 의존 코드는 `scripts/compat.js`에 모았습니다.
- 같은 폴더에 여러 번 내보내도 회차마다 `*.log.json`·`*.player.html`이 따로 남습니다(chat-tools 0.3.1부터).
- 월드 안 재생은 다른 사용자와 동기화되지 않습니다(각자 봄).
