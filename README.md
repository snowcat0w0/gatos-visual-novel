# Gato's Visual Novel (gatos-visual-novel)

이 모듈은 AI를 써서 만들었어요.

## 이게 뭐예요?

Foundry VTT의 채팅을 **비주얼 노벨 게임처럼** 보여 주는 모듈이에요. 캐릭터마다 표정 그림을 여러 개 등록해 두면, 말할 때 화면 위에 그 캐릭터의 스탠딩(전신 그림)이 서고 아래 대사창에 말이 나와요. 지난 대화를 다시 재생해 볼 수도 있어요. 어떤 게임 시스템에서도 써요.

이 폴더의 모듈은 Foundry VTT 13 버전용이에요(`master` 브랜치). 14 버전을 쓰면 `foundry-v14` 브랜치를 받아요.

## 먼저 준비할 것

이 모듈은 **gatos-lib**와 **Gato's Chat Tools(gatos-chat-tools)** 두 모듈이 있어야 돌아가요. 셋 다 설치하고 셋 다 켜 주세요. 하나라도 꺼져 있으면 월드에 들어갈 때 경고가 떠요.

## 설치하는 법

1. Foundry 첫 화면(설정 화면)에서 **애드온 모듈** 탭을 열고 **모듈 설치**를 눌러요.
2. 창 맨 아래 **매니페스트 URL** 칸에 아래 주소를 붙여 넣고 **설치**를 눌러요.

   ```
   https://raw.githubusercontent.com/snowcat0w0/gatos-visual-novel/master/module.json
   ```

3. "gatos-lib와 gatos-chat-tools도 함께 설치할까요?" 하고 물어보면 **예**를 눌러요. 이미 있으면 안 물어봐요.
4. 월드에 들어가서 **게임 설정 → 모듈 관리**에서 **Gato's Library**, **Gato's Chat Tools**, **Gato's Visual Novel**을 모두 체크하고 저장해요.

주소로 설치가 안 되면 [Releases](https://github.com/snowcat0w0/gatos-visual-novel/releases) 페이지에서 `gatos-visual-novel.zip`을 받아 풀고 그 폴더를 `Data/modules/gatos-visual-novel`에 넣어도 돼요.

## 할 수 있는 것들

### 표정과 스탠딩 등록하기

캐릭터 시트 맨 위의 **표정/스탠딩** 버튼을 누르면 편집기가 열려요. 캐릭터 목록에서 우클릭해도 있어요.

- 표정마다 **이름**, **얼굴 그림**(채팅 카드에 쓰여요), **스탠딩 그림**(노벨창에 쓰여요)을 넣어요. 얼굴만 있거나 스탠딩만 있어도 돼요. 비어 있으면 다른 그림으로 대신해요.
- 모든 캐릭터에는 지울 수 없는 **기본** 표정이 하나 있어요.
- 왼쪽 목록에서 끌어서 순서를 바꿔요. 아래에서 이 캐릭터 스탠딩의 크기와 위아래 위치를 맞춰요.
- 캐릭터 주인이나 GM이 고칠 수 있어요.

### 표정 고르기

채팅 입력창 위 발화자 바 아래에 **표정 줄**이 생겨요. 누르면 그 캐릭터의 표정이 바뀌고 다음 말부터 그 얼굴로 나가요.

한 번만 다른 표정으로 말하고 싶으면 메시지 맨 앞에 `{웃음} 안녕!` 처럼 표정 이름을 중괄호로 써요. 태그는 지워지고 그 메시지만 웃는 얼굴로 나가요.

보낸 메시지에는 그때의 얼굴과 스탠딩이 **저장**돼요. 나중에 그림을 바꿔도 이미 올라간 카드는 그대로예요.

### 노벨창

채팅창과 핫바를 뺀 화면 위에 스탠딩과 대사창이 떠요. 그 위로 토큰을 고르고 움직이는 건 그대로 돼요.

- 말한 캐릭터가 무대에 서고 대사창에 이름과 대사가 나와요. 지금 말하는 캐릭터만 컬러고 나머지는 회색이에요.
- 동시에 최대 6명까지 서요. 자리가 없으면 가장 오래 말 안 한 캐릭터가 내려가요.
- 귓속말은 받은 사람 화면에만 나와요. 잡담은 무대에 안 나와요.
- 접속하거나 새로고침하면 최근 메시지로 무대를 다시 만들어서 늦게 들어온 사람도 같은 무대를 봐요.
- 대사창 오른쪽 위에 **▾ 접기**, **빗자루**(GM: 모두의 무대 비우기), **×**(노벨창 끄기)가 있어요. 대사창을 누르면 타자 효과가 바로 끝나요.
- GM이 **Alt를 누른 채 스탠딩을 우클릭**하면 모두의 무대에서 그 스탠딩을 내려요.

### 노벨창 켜고 끄기

채팅 아래 **가면 아이콘**으로 내 노벨창을 켜고 꺼요. 키 설정에서 단축키를 정할 수도 있어요.

가면을 **우클릭**하면 메뉴가 나와요. 무대 다시 구성, 키워드 등록부, 로그 재생이 있고 GM에게는 전원 노벨창 켜기·끄기와 전원 무대 비우기도 있어요. 플레이어가 마음대로 켜고 끄지 못하게 하려면 설정 "플레이어가 노벨창을 켜고 끌 수 있음"을 꺼요.

### 키워드 링크와 참조 이미지

채팅에 `{{해변 사진}}` 처럼 쓰면 그 이름의 액터, 아이템, 저널로 가는 링크가 돼요. `{{해변 사진|그 사진}}` 이라고 쓰면 "그 사진"이라는 글자로 보여요.

- 보낸 사람이 그 문서를 볼 권한이 있어야 링크가 만들어져요. 안 되면 글자 그대로 남고 경고가 떠요.
- 링크가 있는 메시지가 오면 노벨창 가운데에 그 문서의 그림이 떠요. 누르면 문서가 열려요. 권한이 없는 사람에게는 자물쇠 카드가 나와요. 다음 대사가 오면 사라져요.
- **키워드 등록부**(가면 우클릭)에서 키워드와 문서를 짝지어 두면 이름이 달라도 찾아요. 문서를 창에 끌어다 놓으면 돼요.

### 지난 대화 다시 보기 (로그 플레이어)

**월드 안에서**: 가면 우클릭 → **로그 재생…** 에서 지금 채팅이나 저장된 아카이브를 골라요. 또는 Chat Tools의 아카이브 뷰어에서 **노벨로 재생** 버튼을 눌러요. 노벨창 위에 재생 막대가 생겨요. 처음, 이전, 재생, 다음, 끝, 속도(0.5~3배), 메시지 목록. 나한테만 보이는 재생이라 다른 사람 화면은 안 바뀌어요.

**컴퓨터에서**: Chat Tools로 채팅을 ZIP이나 폴더로 내보내면 `<이름>.player.html` 파일이 같이 들어가요. 그 파일을 더블클릭하면 아무 브라우저에서나 노벨창으로 재생돼요. 설치도 인터넷도 필요 없어요. 폴더째로 친구에게 보내도 돼요. 키보드는 Space(재생/정지), →(다음), ←(이전), Home/End예요.

**편집기**: 내보낸 플레이어의 재생 막대에서 **✎**를 누르면 오른쪽에 편집기가 열려요. 잘못 친 대사, 표정, 화자를 고치고 줄을 지우거나 끼워 넣고 배경 그림을 깔 수 있어요. **Ctrl+S**로 저장하면 내보낸 폴더의 파일이 바뀌어요. 폴더에 쓸 수 없는 브라우저(Firefox 등)에서는 **⤓ 내려받기**로 받아서 바꿔 넣어요.

### Chat Tools와 함께

채팅 카드, 아카이브 뷰어, HTML 내보내기에 고른 표정의 얼굴이 쓰여요. 얼굴에 마우스를 올리면 표정 이름이 나와요. ZIP·폴더 내보내기에는 스탠딩과 얼굴 그림, 링크된 문서 페이지도 함께 들어가요.

## 설정

**게임 설정 → 모듈 설정 → Gato's Visual Novel**에서 바꿔요. "나만"은 내 화면에만 적용되고 "월드"는 GM이 바꾸면 모두에게 적용돼요.

| 설정 | 누구 | 처음 값 |
|---|---|---|
| 노벨창 표시 | 나만 | 켬 |
| 플레이어가 노벨창을 켜고 끌 수 있음 | 월드 | 켬 |
| 전투 중 숨김 | 나만 | 끔 |
| 동시 스탠딩 수 | 월드 | 6 |
| 스탠딩 배치 / 높이(%) / 말하지 않는 스탠딩 | 월드 기본값 | 고르게 / 85 / 회색 |
| 대사창 불투명도 / 글자 크기 / 타자 효과 | 월드 기본값 | 0.8 / 18px / 0(즉시) |
| 참조 이미지 표시 | 나만 | 켬 |
| OOC 메시지 / 굴림 메시지 | 나만 | GM의 OOC만 서술로 / 무시 |
| 무대 복원 메시지 수 | 나만 | 40 |
| 자동 퇴장(분) | 월드 | 0(없음) |
| 표정 선택 표시 | 나만 | 썸네일 |
| 인라인 표정 태그 / 인라인 태그로 현재 표정 바꾸기 | 월드 / 나만 | 켬 / 끔 |
| 키워드 링크 최소 권한 | 월드 | 관찰자 |
| 내보내기에 스탠딩/얼굴 포함 | 월드 | 켬 |

화면 모양(스탠딩 배치·높이·회색 처리, 대사창 불투명도·글자 크기, 타자 효과)은 GM이 정한 값이 모두의 기본이에요. 내 화면만 다르게 보고 싶으면 **노벨창 화면 설정 (개인)** 메뉴에서 바꾸고 싶은 항목만 "내 값 사용"으로 체크해요.

## 알아두기

- 노벨창은 캔버스 위, 창과 사이드바 아래에 깔려서 창이나 토큰 메뉴를 가리지 않아요. 비슷한 모듈(theatre, lichsoma-speaker-stage, cinematic-cut-ins)과 같이 켜면 겹칠 수 있어요.
- 월드 안 재생은 각자 따로 봐요. 다른 사람과 같이 재생되지 않아요.
- 매크로나 다른 모듈을 만드는 사람은 `game.modules.get("gatos-visual-novel").api`에서 함수들을 쓸 수 있어요. 목록은 `scripts/module.js`를 보세요.
